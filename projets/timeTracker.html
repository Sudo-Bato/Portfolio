1. Le Besoin Initial

Project réalisé pour un ami musicien qui souhaitait organiser ses sessions de pratique (Piano, Solfège, Composition) sans s'encombrer d'une usine à gaz ou d'une application nécessitant un abonnement.

Contraintes :
  • ⚡ Rapidité : Lancer un chronomètre en 1 clic.
  • 🔒 Privé : Pas de compte, pas de tracking externe, tout reste sur l'ordinateur.
  • 📊 Visuel : Voir en un coup d'œil où passe le temps chaque semaine.

Fonctionnalités Clés

Tracking en Temps Réel

Un timer minimaliste et discret conçu pour ne pas distraire. Lancez votre session en un clic, sélectionnez votre activité, et laissez l'application tourner en arrière-plan pendant que vous vous concentrez sur l'essentiel.

Analyses & Statistiques

Visualisez votre progression grâce à des graphiques dynamiques. Analysez la répartition de votre temps par catégorie sur la semaine et identifiez vos jours les plus productifs d'un simple coup d'œil.

Profil & Paramètres

Personnalisez vos catégories de travail et gérez vos données. L'application permet un export/import complet de vos données au format JSON, vous garantissant la pleine maîtrise de vos informations.

2. Architecture & Fonctionnalités

L'application utilise Electron pour encapsuler une application web React moderne. Cela permet d'avoir accès au système de fichiers natif tout en gardant une interface fluide développée avec les standards du web.

⚛️
Store Context

Gestion de l'état global (Timer actif, Logs, Catégories) via React Context API, avec persistance automatique dans le localStorage à chaque modification.

📈
Visualisation

Intégration de Recharts pour générer des graphiques dynamiques : Pie Chart pour la répartition et Bar Chart pour l'intensité quotidienne.

📦
Build & Release

Configuration de scripts npm personnalisés pour builder l'application sur toutes les architectures cibles :

npm run build:mac:arm
npm run build:win:intel

3. Gestion des Données

L'application inclut un système d'export/import JSON complet pour permettre la sauvegarde manuelle ou le transfert de données entre deux machines.
