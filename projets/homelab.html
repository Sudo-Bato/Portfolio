Opérationnel

1. 🏗️ Les Fondations (Système & Réseau)

La Forteresse (Sécurité Zero Trust)

Contrairement à une configuration classique, aucun port n'est ouvert sur ma Box Internet (pas de NAT/Port Forwarding). Le serveur est donc invisible aux scanners de ports malveillants.

  • 🛡️ Cloudflare Tunnel : Tout le trafic passe par un tunnel chiffré sortant.
  • 🔒 HTTPS Automatique : Gestion des certificats SSL via Cloudflare pour le domaine.

2. ⚙️ Le Moteur (Virtualisation)

L'intégralité des services tourne sous Docker, orchestré par Docker Compose et piloté via l'interface web Portainer.

Challenges Techniques Résolus :
  • Compatibilité Docker sur Ubuntu 24.04 (gestion des paquets apt-mark).
  • Contournement des restrictions AppArmor strictes qui bloquaient certains conteneurs (via security_opt: apparmor=unconfined).

3. 📦 Les Applications Hébergées

📷

Immich

Alternative open-source puissante à Google Photos. Permet la sauvegarde automatique des photos depuis mobile, avec reconnaissance faciale en local (Machine Learning) et performances élevées.

🔐

Vaultwarden

Une instance Bitwarden légère en Rust. C'est un coffre-fort de mots de passe souverain : les données sont chiffrées et hébergées chez moi, sans dépendre du cloud public.

🐳

Portainer

Le centre de commandement. Une GUI intuitive pour déployer des stacks, surveiller les logs en temps réel et gérer le cycle de vie des conteneurs.

4. 🖥️ Le Dashboard (Homarr)

Pour unifier l'accès à tous ces services, j'ai choisi Homarr après avoir testé plusieurs alternatives (Glance, Homepage).

  • ✨ Configuration Graphique : 100% Drag & Drop, fini les fichiers YAML imbuvables.
  • 🎨 Design Moderne : Personnalisation poussée avec du CSS moderne (oklch) pour une interface réactive et agréable.
